# AI contributor guide

Start here before making an AI-assisted change to CoilVision Frontend.

Read in this order:

1. `context/project.md` for the product state and boundaries.
2. `rules/architecture.md` for dependency and folder rules.
3. `rules/frontend.md` for implementation and quality rules.
4. `rules/api-integration.md` before adding any backend endpoint.
5. `skills/implement-feature.md` when building a feature.

These files are repository guidance, not a replacement for reviewing the current code. An AI tool must inspect relevant files and preserve existing behavior before editing.
